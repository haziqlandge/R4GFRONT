# GPU dependencies for OFFLINE index building only. Phase 3.

# DO NOT install these on BENCH. Its GT 710 is Kepler-class and below the floor
# of every current CUDA wheel, and BENCH's environment is the one every number in
# bench/results/ was measured on (Devices.md 1). Keep it clean.
#
# DO NOT pip install -r this file directly - torch needs a per-GPU index URL that
# a requirements file cannot express. Install torch first with the right URL for
# your card, then this file for the rest.
#
#   EMBED  (RTX 3060 Ti, sm_86 - Ampere):
#     pip install torch --index-url https://download.pytorch.org/whl/cu124
#
#   LLM    (RTX 5070 Ti, sm_120 - Blackwell):
#     pip install torch --index-url https://download.pytorch.org/whl/cu128
#
# sm_120 needs CUDA 12.8 or newer. An older wheel installs cleanly and then dies
# at the first kernel launch with "no kernel image is available for execution on
# the device", which reads as a broken install rather than an architecture
# mismatch. Always smoke-test with a REAL forward pass, not torch.cuda
# .is_available() - that returns True on a mismatched build. See ISSUES.md I14
# and PREREQUISITES.md 2.3.
